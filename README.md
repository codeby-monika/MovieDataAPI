# MovieDataAPI

A simple Java Spring Boot REST API to manage a collection of movies and series.

## Features

- Pre-populated with sample movies/series:
  - Harry Potter
  - Spider-Man
  - Stranger Things
  - Alice in Borderland
  - All of Us Are Dead
  - Squid Game
- Add new movies
- Get movie by ID
- Simple in-memory storage (ArrayList)

## Requirements

- Java 11 or higher
- Maven
- Spring Boot
